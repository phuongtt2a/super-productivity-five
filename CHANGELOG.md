# Changelog

## 3.1.0 — Five

- Renamed the public-facing product to **Five**, by **phuongtt2a**.
- Made **Arrange Five** the single place to pick, create, and reorder tasks.
- Added **five independent, persistent positions**, including intentionally empty positions.
- Drag a task to any slot; moving existing tasks swaps their positions rather than compacting the list.
- Added accessible up/down controls for moving tasks without drag-and-drop.
- Kept the quiet, typography-led focus view, with the first task most prominent.
- Added reproducible plugin packaging, CI, release automation, and open-source documentation.

## 3.0.0 — Typography-first focus

- Replaced boxed cards with five uncluttered ranked lines.
- Added a separate planner with task search, due-date and priority sorting, and task creation.
- Added completion-aware free slots and daily persisted selections.

## Earlier local builds

- **2.0:** Separated focus and management views.
- **1.1:** Matched Super Productivity's four-file plugin ZIP structure.
